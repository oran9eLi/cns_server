# 飞控页面数据满足度分析

## 1. 文档目的

本文档用于说明当前系统已经收到并完成适配的真实遥测数据，可以支撑飞控页面中的哪些内容，以及哪些内容仍需补充设备字段或业务协议。

- 分析日期：2026-07-22
- 分析范围：当前 `frontend`、`backend_service` 已实现的数据协议和真实树莓派遥测适配
- 判断原则：仅以已确认收到的字段为依据，不使用模拟数据补齐，不把字段缺失直接判断为模块故障或离线

## 2. 当前已确认收到的数据

当前真实遥测报文中，已经确认并完成前端适配的主要字段如下：

| 数据类别 | 字段 | 含义 |
| --- | --- | --- |
| 姿态 | `telemetry.attitude.roll` | 横滚角 Roll |
| 姿态 | `telemetry.attitude.pitch` | 俯仰角 Pitch |
| 姿态 | `telemetry.attitude.yaw` | 偏航角 Yaw |
| 环境 | `telemetry.pressure.temperature` | 温度 |
| 环境 | `telemetry.pressure.press_abs` | 绝对气压 |
| 电机 | `telemetry.motor.pwm_us[0..3]` | 四路电机 PWM，单位为 μs |
| LoRa | `telemetry.lora.loss_rate_percent` | LoRa 丢包率 |
| 电池 | `telemetry.battery.battery_remaining` | 电池剩余电量百分比 |
| 电池 | `telemetry.battery.voltage_battery` | 电池总电压，当前按 mV 处理 |
| 电池 | `telemetry.battery.voltages[0]` | 电池电压备用来源 |

设备状态事件和设备基础信息还可以提供：

| 字段 | 含义 |
| --- | --- |
| `vendor_id` | 设备唯一编号 |
| `dcdw_label` | 页面展示编号，例如 DCDW-001 |
| `status` | 设备在线或离线状态 |
| `last_seen_at` | 设备最后活跃时间 |
| `telemetry_received_at` | 最新遥测接收时间 |
| `event_at` | 实时状态事件时间 |
| `degraded` | 当前状态是否为降级状态 |

## 3. 页面内容满足情况

### 3.1 可以直接满足

| 页面内容 | 满足情况 | 数据来源或实现方式 |
| --- | --- | --- |
| 横滚 ROLL | 可以 | `telemetry.attitude.roll` |
| 俯仰 PITCH | 可以 | `telemetry.attitude.pitch` |
| 偏航 YAW | 可以 | `telemetry.attitude.yaw` |
| 中间姿态仪动画 | 可以 | 根据 Roll、Pitch、Yaw 绘制 |
| 温度 | 可以 | `telemetry.pressure.temperature` |
| 气压 | 可以 | `telemetry.pressure.press_abs` |
| 一号至四号电机 PWM | 可以 | `telemetry.motor.pwm_us[0..3]` |
| LoRa 丢包率 | 可以 | `telemetry.lora.loss_rate_percent` |
| 一组电池电量 | 可以 | `telemetry.battery.battery_remaining` |
| 一组电池电压 | 可以 | 优先使用 `voltage_battery`，缺失时使用 `voltages[0]` |
| 设备编号 | 可以 | `dcdw_label` 或 `vendor_id` |
| 设备在线/离线状态 | 可以 | `status` |
| 最后活跃时间 | 可以 | `last_seen_at` |
| 遥测更新时间 | 可以 | `telemetry_received_at` 或 `event_at` |
| 页面当前时间和日期 | 可以 | 使用浏览器本地时间，不依赖设备遥测 |

### 3.2 可以通过计算或有限推断满足

| 页面内容 | 满足情况 | 说明 |
| --- | --- | --- |
| PWM 百分比 | 可计算 | 可按 `1000μs = 0%`、`2000μs = 100%` 进行线性换算，并限制在 0%～100% |
| 姿态模块“有数据” | 可有限推断 | 收到新鲜的 Roll、Pitch、Yaw 时可以显示“有数据”，但不能代表模块无故障 |
| 环境模块“有数据” | 可有限推断 | 收到新鲜的温度或气压时可以显示“有数据” |
| LoRa 模块“有数据” | 可有限推断 | 收到丢包率时可以证明存在 LoRa 遥测字段，但不能直接证明通信完全正常 |
| M1～M4 数据状态 | 可有限推断 | 可以判断四路 PWM 是否存在，不能判断电机过流、堵转、断开等故障 |

PWM 百分比建议使用以下公式：

```text
PWM 百分比 = (PWMμs - 1000) / (2000 - 1000) × 100%
```

### 3.3 只能部分满足

| 页面内容 | 满足情况 | 原因 |
| --- | --- | --- |
| 主控电压、主控电量 | 部分满足 | 当前只有一组电池电压和电量，尚未明确它属于主控电源还是动力电池 |
| 电机电压、电机电量 | 部分满足 | 当前只有一组电池数据，不能与主控电池同时独立展示 |
| LoRa 通信状态 | 部分满足 | 有丢包率，但缺少明确的在线状态、RSSI、发送数、接收数和延迟 |
| 系统状态列表 | 部分满足 | 只能根据部分遥测字段判断“是否有数据”，缺少权威模块健康状态 |
| 底部丢包率 | 可以 | 可使用 `loss_rate_percent` |
| 底部发送数、接收数 | 不能 | 当前没有累计收发计数字段 |

> 电池数据在协议明确前，只能选择页面中的一组电池卡片进行展示，不应同时复制到“主控”和“电机”两组卡片中。

### 3.4 当前不能满足

以下页面内容在当前已确认的真实遥测中没有对应字段：

| 页面内容 | 缺少的数据 |
| --- | --- |
| 湿度 | 湿度值及单位 |
| 定位模块状态 | 定位模块健康状态或在线状态 |
| 经纬度 | 纬度、经度 |
| 定位类型 | 无定位、2D、3D 等定位状态 |
| 卫星数量 | 可用卫星数 |
| 5G 通信状态 | 5G 在线状态、信号质量、故障信息 |
| RemoteID 状态 | RemoteID 模块状态和发送状态 |
| 存储模块状态 | 存储是否正常、容量、挂载或读写状态 |
| 模块自检结果 | 各模块明确的健康状态和故障原因 |
| 告警编码 | 例如 `0x0301`、`0x0204` |
| 告警汇总 | 当前告警列表、等级、数量和产生时间 |
| 消息日志 | 模块状态变化、告警恢复和操作记录等历史事件 |
| 发送数量、接收数量 | 通信累计计数 |
| 飞行状态 | 待机、起飞中、飞行中、降落中等权威状态 |
| 两套独立电池 | 主控电源和动力电池各自的电压、电量 |

## 4. 控制功能支持情况

当前控制协议已经支持以下页面操作：

| 页面操作 | 协议命令 | 支持情况 |
| --- | --- | --- |
| 设置四路 PWM | `set_motor_pwm` | 支持 |
| 一键起飞 | `takeoff` | 支持 |
| 降落 | `land` | 支持 |
| 急停 | `emergency_stop` | 支持 |

命令执行后，可以收到以下状态：

- 已提交：`submitted`
- 已派发：`dispatched`
- 执行中：`in_progress`
- 执行成功：`succeeded`
- 执行失败：`failed`
- 执行超时：`timeout`
- 投递结果不确定：`delivery_uncertain`

这些状态可以用于按钮禁用、操作结果提示和命令执行进度，但不能直接替代页面右侧的系统消息日志。

当前协议没有独立的“自检”控制命令，因此页面左侧“自检”功能仍需补充协议定义。

## 5. 当前建议落地范围

基于现有真实数据，页面第一阶段可以稳定实现：

1. 姿态仪以及 Roll、Pitch、Yaw 数值。
2. 温度和气压展示。
3. 四路电机 PWM 数值及换算后的百分比。
4. LoRa 丢包率。
5. 一组电池电压和电量。
6. 设备编号、在线状态和最新数据时间。
7. 设置 PWM、一键起飞、降落、急停及命令结果反馈。

以下内容建议先显示“暂无数据”或隐藏：

1. 湿度。
2. 定位状态和卫星数量。
3. 5G、RemoteID、存储模块状态。
4. 主控和电机两组独立电池卡片中的另一组。
5. 告警汇总、告警编码和消息日志。
6. 发送数、接收数和权威飞行状态。
