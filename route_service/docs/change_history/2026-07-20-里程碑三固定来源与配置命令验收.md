# 里程碑三固定来源与配置命令验收记录

日期：2026-07-20

## 结论

里程碑三代码已完成固定来源同步、配置命令协议、寻址与权限、双层幂等、PostgreSQL 状态机、QoS 2 发布完成关联、设备 ACK、15 秒超时、原 `command_id` 恢复、30 天限量清理和统一生命周期接线。

本记录只把实际取得证据的项目标为通过。当前提交已经完成本机独立 PostgreSQL/Mosquitto 真实链路；真实 RPi 和现场服务器尚未取得新鲜证据，因此保持“待验证”，不得由本机结果推定通过。

## 已通过

- 本机 Debug 全量构建通过。
- CTest 共 33 项，覆盖配置、协议、来源目录、寻址权限、状态转换、PostgreSQL 仓库与工作线程、MQTT QoS 2/MID 关联、请求幂等、设备 ACK、超时、恢复、清理和生命周期顺序。
- 命令请求严格经过查询、`pending` 持久化、设备发布、MID 完成、`dispatched` 持久化和来源 ACK。
- 成功或拒绝设备 ACK 先持久化终态，再向来源回程；topic 目标不一致不更新命令。
- 已覆盖真实链路出现的早到 ACK 竞态：ACK 先暂存，`dispatched` 落库后再转换并回程 `succeeded`。
- 启动先加载设备、同步来源并加载活动命令，之后才启动线程和 MQTT；迁移模式不执行命令加载。
- 联调脚本通过 shell 语法和只读参数检查；脚本只按测试 `source_id + request_id` 定向删除自身命令，不执行 `TRUNCATE`、`DROP` 或服务启停。
- `/tmp` 独立 PostgreSQL 18.4（端口 55433）和 Mosquitto 2.0.22（端口 18884）真实链路通过：迁移连续执行两次、retained registration 建档、固定 `web-console` 来源请求、QoS 2 设备下发、模拟设备 `applied` ACK、来源 `dispatched/succeeded` 回程和定向命令清理均成功；临时服务和数据目录已在退出时清理。
