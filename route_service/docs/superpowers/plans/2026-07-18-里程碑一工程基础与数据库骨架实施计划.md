# Route Service 里程碑一工程基础与数据库骨架实施计划

> **面向智能代理执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，逐任务执行本计划。所有步骤使用复选框跟踪。

**目标：** 构建一个可严格配置、可测试、可显式迁移数据库、可维持 MQTT 连接并能优雅退出的 C++23 `route_service` 基础程序。

**架构：** 工程只部署一个 `route_service` 可执行程序；内部由不依赖外部服务的 `route_core`、封装 libpqxx/libmosquitto 的 `route_adapters` 和负责生命周期的进程入口组成。数据库迁移由纯逻辑规划器与 PostgreSQL 执行器分离，正常启动只检查版本，`--migrate-only` 才执行 SQL。

**技术栈：** C++23、CMake、doctest、nlohmann/json、libpqxx、libmosquitto、PostgreSQL。

  cns::queue::BoundedQueue<int> queue(2);
  CHECK(queue.TryPush(1));
  CHECK(queue.TryPush(2));
  CHECK_FALSE(queue.TryPush(3));
}

TEST_CASE("关闭后先按FIFO排空再返回关闭") {
  cns::queue::BoundedQueue<int> queue(2);
  REQUIRE(queue.TryPush(1));
  REQUIRE(queue.TryPush(2));
  queue.Close();
  CHECK(queue.WaitPop() == 1);
  CHECK(queue.WaitPop() == 2);
  CHECK_FALSE(queue.WaitPop().has_value());
