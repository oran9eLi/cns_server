# 临时 FRP 公网联调实施计划

> **执行要求：** 使用 `superpowers:executing-plans` 在当前会话逐项执行；本计划不使用子代理。

**目标：** 使用本机 systemd 托管的 frpc 0.70.0 将云服务器 `112.124.52.232:1883` 转发到本机 Mosquitto `127.0.0.1:18884`，让一台树莓派在本机短期承担服务器期间通过公网持续接入并完成 route_service 全链路展示。

**架构：** 云服务器现有 frps 0.70.0 接收公网 TCP `1883`，通过 frp 控制连接把原始 MQTT TCP 流量转发给本机 frpc；frpc 再连接本机现有 Mosquitto `127.0.0.1:18884`。route_service 和 PostgreSQL 保持当前本机临时联调配置不变。

**技术栈：** frp 0.70.0、Mosquitto 2.0.22、Route Service C++23、PostgreSQL。

## 全局约束

- 本次是临时展示链路，不实施 MQTT TLS、用户名密码、ACL 或 frp token。
- 已确认临时接受公网来源不限和匿名 MQTT 风险。
- 不把真实运行配置或任何秘密提交到 Git；仓库只保留实施计划，frpc 配置安装在 `/etc/frp/`。
- 用户已经明确授权在本机持久安装 frpc 并配置 systemd 开机自启；不修改云服务器和树莓派，除非用户另行明确授权。
- 不停止现有本机 Mosquitto 和 PostgreSQL；用户未要求前不得清理临时环境。
- 公网入口为 `112.124.52.232:1883`，本地目标为 `127.0.0.1:18884`。

### 任务 2：安装 frpc 0.70.0

**文件：**

- 创建：`/usr/local/bin/frpc`

- [ ] 从 frp 官方 GitHub Release 下载 Linux 对应架构的 0.70.0 发布包到一次性临时目录。
- [ ] 使用官方校验和验证发布包，并执行 `frpc --version`，期望输出 `0.70.0`。
- [ ] 把 frpc 可执行文件安装为 `/usr/local/bin/frpc`，所有者为 root，权限为 `0755`。

### 任务 3：生成并校验临时 frpc 配置

**文件：**

- 创建：`/etc/frp/frpc.toml`

- [ ] 写入唯一 TCP 代理：

```toml
serverAddr = "112.124.52.232"
serverPort = 7000
transport.tls.enable = true

[[proxies]]
name = "cns-mqtt-demo"
type = "tcp"
localIP = "127.0.0.1"
localPort = 18884
remotePort = 1883
```

- [ ] 执行：

```bash
/usr/local/bin/frpc verify -c /etc/frp/frpc.toml
```

期望：配置校验成功且退出码为 0。

### 任务 4：配置 systemd 自启动并验证公网 MQTT

**文件：**

- 创建：`/etc/systemd/system/cns-frpc.service`

- [ ] 创建专用 systemd 单元，等待网络就绪后启动，异常退出自动重启，并以前台模式运行：

```ini
[Unit]
Description=CNS FRP 公网 MQTT 转发
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
ExecStart=/usr/local/bin/frpc -c /etc/frp/frpc.toml
Restart=on-failure
RestartSec=5s
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

- [ ] 执行 `systemctl daemon-reload` 和 `systemctl enable --now cns-frpc.service`。
- [ ] 确认服务处于 `active (running)` 且已启用开机启动。
- [ ] 从树莓派确认 `112.124.52.232:1883` TCP 可达。
- [ ] 向用户提供树莓派真实配置中需要修改的 MQTT host 和 port，以及前台启动命令；不直接修改树莓派配置。
- [ ] 树莓派启动后，确认 frpc 无代理错误，本机 Broker 出现客户端连接，route_service 收到 registration 和 telemetry。
