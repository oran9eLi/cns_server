# 临时 FRP 公网联调实施计划

> **执行要求：** 使用 `superpowers:executing-plans` 在当前会话逐项执行；本计划不使用子代理。

**目标：** 使用本机 frpc 0.70.0 将云服务器 `112.124.52.232:1883` 临时转发到本机 Mosquitto `127.0.0.1:18884`，让一台树莓派通过公网接入并完成 route_service 全链路展示。

**架构：** 云服务器现有 frps 0.70.0 接收公网 TCP `1883`，通过 frp 控制连接把原始 MQTT TCP 流量转发给本机 frpc；frpc 再连接本机现有 Mosquitto `127.0.0.1:18884`。route_service 和 PostgreSQL 保持当前本机临时联调配置不变。

**技术栈：** frp 0.70.0、Mosquitto 2.0.22、Route Service C++23、PostgreSQL。

## 全局约束

- 本次是临时展示链路，不实施 MQTT TLS、用户名密码、ACL 或 frp token。
- 已确认临时接受公网来源不限和匿名 MQTT 风险。
- 不把弹性公网 IP、真实运行配置或任何秘密提交到 Git；frpc 配置放在 `/tmp/cns-frpc-demo/`。
- 不修改云服务器、树莓派或本机系统服务，除非用户在对应步骤明确授权。
- 不停止现有本机 Mosquitto 和 PostgreSQL；用户未要求前不得清理临时环境。
- 公网入口为 `112.124.52.232:1883`，本地目标为 `127.0.0.1:18884`。

### 任务 3：生成并校验临时 frpc 配置

**文件：**

- 创建：`/tmp/cns-frpc-demo/frpc.toml`

- [ ] 写入唯一 TCP 代理：

```toml
serverAddr = "112.124.52.232"
serverPort = 7000
transport.tls.enable = true

[[proxies]]
name = "cns-mqtt-demo"
type = "tcp"
localIP = "127.0.0.1"
localPort = 18884
remotePort = 1883
```

- [ ] 执行：

```bash
/tmp/cns-frpc-demo/frpc verify -c /tmp/cns-frpc-demo/frpc.toml
```

期望：配置校验成功且退出码为 0。
