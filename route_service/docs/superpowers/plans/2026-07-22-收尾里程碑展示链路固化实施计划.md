# 收尾里程碑展示链路固化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 固化当前本机展示链路，修复 Broker 晚启动后业务订阅不可靠恢复、配置命令状态转换误报，并补齐遥测供给与部署验收文档。

**架构：** 保持现有 route_service 协议、数据库表结构和命令状态机不变，只在 MQTT 适配层增加业务订阅恢复闭环，在命令运行时增加数据库状态转换失败分类与收敛。验收以本机展示链路为准，不声明现场硬件服务器通过。

**技术栈：** C++23、libmosquitto、PostgreSQL、nlohmann/json、doctest、CMake、systemd、Nginx、Markdown。

## 全局约束

- 所有文档、代码注释、运行日志、提交说明正文和回答使用中文；Git 提交前缀保持英文，例如 `fix: 中文说明`。
- 日常开发在本机完成；不依赖数据库和 Broker 的单元测试在本机运行。
- 不修改树莓派协议，不改变 registration retained、telemetry 非 retained、配置 ACK 或飞控 ACK 的既有语义。
- 不新增遥测历史存储、数据库业务表、正式 MQTT TLS/ACL/8883、Web 用户鉴权或前端失败原因展示。
- 数据库迁移必须版本化、幂等、可重复执行；本计划默认不新增迁移。
- 测试不得清空或破坏已有服务器数据；真实配置、密码、证书私钥和数据库数据目录不得提交。
- 当前收尾验收只声明“本机展示链路通过”，不得写成“现场服务器通过”。

```cpp
std::expected<std::optional<command::CommandRecord>, std::string>
PostgresStore::FindCommandById(std::string_view command_id) {
  try {
    pqxx::read_transaction transaction{*connection_};
    const auto rows = transaction.exec(
        "SELECT " + std::string{kCommandColumns} +
            " FROM commands WHERE command_id = $1::uuid",
        pqxx::params{command_id});
    if (rows.empty()) return std::optional<command::CommandRecord>{};
    auto record = CommandFromRow(rows.front());
    if (!record) return std::unexpected(record.error());
    return std::optional<command::CommandRecord>{std::move(*record)};
  } catch (const pqxx::broken_connection&) {
    last_failure_kind_ = ClassifyOperationFailure(IsOpen(), true);
    return std::unexpected("查询 PostgreSQL 命令失败");
  } catch (const std::exception&) {
    last_failure_kind_ = ClassifyOperationFailure(IsOpen(), false);
    return std::unexpected("查询 PostgreSQL 命令失败");
  }
}
```

```cpp
void CommandService::ConvergeAfterConflict(Operation operation,
                                           const command::CommandRecord& current,
                                           command::TimePoint now) {
  if (!operation.context.record) return;
  auto desired_context = std::move(operation.context);
  const auto desired = *desired_context.record;
  desired_context.record = current;
  desired_context.target = TargetFor(current);

  if (current.status == desired.status ||
      command::IsTerminal(current.status)) {
    if (command::IsTerminal(current.status)) {
      active_commands_.erase(current.command_id);
      recovery_started_.erase(current.command_id);
      early_device_acks_.erase(current.command_id);
    } else {
      active_commands_.insert_or_assign(current.command_id, desired_context);
    }
    PublishAck(desired_context, now);
    return;
  }

  if (command::CanTransition(current.status, desired.status)) {
    command::CommandUpdate update{
        .error_code = desired.error_code,
        .error_message = desired.error_message,
        .device_ack = desired.device_ack,
        .dispatched_at = desired.dispatched_at,
        .completed_at = desired.completed_at,
        .updated_at = desired.updated_at};
    desired_context.record = desired;
    SubmitTransitionOrDefer(
        std::move(desired_context),
        TransitionCommandTask{current.command_id, current.status,
                              desired.status, std::move(update)});
    return;
  }

  Diagnose("命令状态变化后无法收敛当前状态");
}
```

实施时如发现 `PublishAck` 会导致终态 ACK 重复，改为在 `current.status == desired.status` 且当前来源已发过同状态 ACK 的路径只清理内存，不再发布；测试必须明确覆盖。
