# 路由服务 V1 实施计划

> **供执行代理使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，逐任务执行本计划并在每个任务后复核。

**目标：** 实现可在现场服务器单实例运行的 C++23 route_service，完成设备注册、最新遥测状态、实时状态事件、配置与飞控命令路由、ACK 回程及 PostgreSQL 持久化。

**架构：** libmosquitto 网络回调只把消息复制到有界队列，单业务线程负责协议和状态机，单数据库线程通过 libpqxx 执行事务。稳定设备元数据与高频最新状态分表，实时状态事件立即发布，遥测默认每 5 秒合并落库。

**技术栈：** C++23、CMake、libmosquitto、libpqxx、nlohmann/json、doctest、PostgreSQL、Mosquitto、systemd。

## 全局约束

- 所有文档、代码注释、运行日志和提交说明正文使用中文；协议字段、类型名和错误码保留英文。
- 所有新增 `.hpp/.cpp` 使用中文 Doxygen 文件头，公开接口说明职责、参数、失败语义和线程边界。
- 提交格式为 `<type>: <简短中文说明>`。
- V1 面向当前不足 10 台设备，不引入多实例、遥测历史、Web 框架或复杂优先级队列。
- registration 使用 QoS 2、`retain=true`；telemetry 使用 QoS 0、`retain=false`。
- PostgreSQL 迁移必须版本化、幂等、可重复执行，不得清空已有数据。
- 不提交密码、现场配置、证书私钥或 PostgreSQL 数据目录。
- 本机只运行不依赖 PostgreSQL/Mosquitto 的单元测试；现场依赖测试必须在服务器拉取对应提交后执行。
- 未经用户单独授权，不安装服务器软件、不执行迁移、不修改 Mosquitto 或 systemd 状态。
- 设计依据：`route_service/docs/superpowers/specs/2026-07-18-路由服务V1设计.md`。
