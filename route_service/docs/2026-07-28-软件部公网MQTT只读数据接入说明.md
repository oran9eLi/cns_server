# 软件部公网 MQTT 只读数据接入说明

## 1. 接入范围

软件部只需连接公网 MQTT，不需要访问 PostgreSQL 或调用 `backend_service`。服务端同时发布 CNS 主控箱和 PX4 真实飞控数据，接入方想看哪类就按需展示，不要求只处理主控箱。

统一字段：

- `device_id`：设备唯一标识，来自设备的 `OPEN_DRONE_ID_BASIC_ID.uas_id`；
- `device_type`：`cns_box` 表示主控箱，`flight_controller` 表示 PX4；
- `school_name`、`dcdw_label`：归属信息，PX4 可以为 `null`；
- `capabilities`、`product`、`version`：设备能力、产品和版本元数据，可以为 `null`。

接口中不再提供 `vendor_id`、PX4 硬件 UID、树莓派编号或网关编号。设备 ID 不应按前缀推断类型，以 `device_type` 为准。

## 2. 公网连接参数

| 参数 | 当前值 |
|---|---|
| Broker | `112.124.52.232` |
| TCP 端口 | `1883` |
| MQTT 版本 | MQTT 3.1.1 |
| 目录和状态 QoS | `1` |
| PX4 高频帧 QoS | `0` |

当前 Broker 为匿名明文服务，暂未通过 ACL 强制只读。软件部客户端只能订阅本文列出的 topic，不得向 CNS topic 发布消息。

## 3. 全量设备目录

订阅：

```text
cns_rpi/events/devices/directory
```

该 topic 为 QoS 1、retained 的完整快照。客户端每次收到后应整体替换本地设备目录，不要按增量合并。

```json
{
  "schema_version": 1,
  "event_type": "device_directory_snapshot",
  "generated_at": "2026-08-03T10:00:00.000Z",
  "revision": 6,
  "devices": [
    {
      "device_id": "DCDWCNS1S2MEAG1VTA0C",
      "device_type": "cns_box",
      "school_name": "SEU",
      "dcdw_label": "DCDW-001",
      "model_version": "CNS v1.0",
      "capabilities": ["telemetry", "remote_id", "runtime_config"],
      "product": {
        "manufacturer_code": "DCDW",
        "model_code": "CNS1"
      },
      "version": null,
      "status": "online"
    },
    {
      "device_id": "PX4RID123456789ABCDE",
      "device_type": "flight_controller",
      "school_name": null,
      "dcdw_label": null,
      "model_version": "PX4",
      "capabilities": ["telemetry", "remote_id", "px4_official_control"],
      "product": {
        "manufacturer_code": "26",
        "model_code": "7"
      },
      "version": {
        "hardware": "42",
        "firmware": "1.17.3"
      },
      "status": "online"
    }
  ]
}
```

没有设备时 `devices` 为空数组。目录按 `device_id` 排序，会在服务启动、MQTT 重连、新设备入库、设备上下线或目录元数据变化时重新发布。

## 4. 单设备当前状态与完整遥测

订阅全部设备：

```text
cns_rpi/events/devices/+/state
```

`+` 代表一个 `device_id`。该 topic 为 QoS 1、retained 的单设备完整当前快照；重连后可立即恢复每台设备的最近状态。

```json
{
  "schema_version": 1,
  "event_type": "device_state",
  "event_at": "2026-08-03T10:00:01.125Z",
  "revision": 590,
  "device_id": "PX4RID123456789ABCDE",
  "device_type": "flight_controller",
  "school_name": null,
  "dcdw_label": null,
  "model_version": "PX4",
  "capabilities": ["telemetry", "remote_id", "px4_official_control"],
  "product": {
    "manufacturer_code": "26",
    "model_code": "7"
  },
  "version": {
    "hardware": "42",
    "firmware": "1.17.3"
  },
  "status": "online",
  "last_seen_at": "2026-08-03T10:00:01.120Z",
  "telemetry_received_at": "2026-08-03T10:00:01.120Z",
  "latest_telemetry": {
    "schema_version": 3,
    "device_id": "PX4RID123456789ABCDE",
    "device_type": "flight_controller",
    "sent_at": "2026-08-03T10:00:01Z",
    "telemetry": {
      "heartbeat": {
        "system_status": 4
      }
    },
    "drone_id": {
      "basic_id": {
        "id_type": 1,
        "ua_type": 2
      }
    }
  },
  "change_reason": "telemetry",
  "degraded": false
}
```

说明：

- 外层状态快照的 `schema_version` 当前为 `1`；
- `latest_telemetry` 是 RPi 上报的完整慢速遥测，内部 `schema_version` 固定为 `3`；
- 慢速遥测约 1 Hz，具体字段随设备能力扩展，客户端应允许未知字段；
- `drone_id.basic_id` 保留 `id_type`、`ua_type`，设备身份只看顶层 `device_id`；
- 离线快照仍保留最后一帧遥测，但只能视为离线前的最后值。

`change_reason` 可能为 `registration_online`、`registration_offline`、`telemetry`、`activity_timeout`、`database_recovered` 或 `snapshot_replay`。

## 5. PX4 高频实时帧（可选）

如需看 PX4 姿态、位置等低延迟数据，额外订阅：

```text
cns_rpi/+/px4/realtime/v1
```

高频帧约 20 Hz、QoS 0、非 retained、不入库、断线不补发。它保持独立的 `schema_version: 1`，但 `device_id` 同样使用 Basic ID。

```json
{
  "schema_version": 1,
  "device_id": "PX4RID123456789ABCDE",
  "sequence": 12345,
  "sent_at": "2026-08-03T10:00:01.125Z",
  "telemetry": {
    "attitude": {
      "roll_deg": 1.2,
      "pitch_deg": -0.8,
      "yaw_deg": 86.4
    },
    "global_position": {
      "lat": 31.230416,
      "lon": 121.473701,
      "alt": 18.6,
      "hdg": 86.4
    },
    "battery": {
      "voltage_v": 15.7,
      "remaining_percent": 78
    }
  }
}
```

客户端只保留最新高频帧即可，不要在弱网恢复后排队处理过期帧。身份和完整遥测仍以 retained 单设备状态为准。

## 6. 命令行验证

订阅目录和全部设备状态：

```bash
mosquitto_sub \
  -h 112.124.52.232 \
  -p 1883 \
  -V mqttv311 \
  -q 1 \
  -i "software-read-本机唯一标识" \
  -v \
  -t 'cns_rpi/events/devices/directory' \
  -t 'cns_rpi/events/devices/+/state'
```

可选查看 PX4 高频帧：

```bash
mosquitto_sub \
  -h 112.124.52.232 \
  -p 1883 \
  -V mqttv311 \
  -q 0 \
  -i "software-px4-本机唯一标识" \
  -v \
  -t 'cns_rpi/+/px4/realtime/v1'
```

## 7. 当前边界

该接口不提供历史查询、遥测补发、命令下发、命令 ACK、告警处置、数据库访问或 Broker 只读 ACL 保证。客户端离线期间的中间帧不会补发，重连后 retained 消息只恢复最新状态。
