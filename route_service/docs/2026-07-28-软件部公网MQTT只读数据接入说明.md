# 软件部公网 MQTT 只读数据接入说明

## 1. 接入范围

软件部只需连接公网 MQTT，不需要访问 PostgreSQL 或调用 `backend_service`。服务端同时发布
CNS 主控箱和 PX4 真实飞控数据，接入方可以按需要查看任意设备；发布层不区分遥测由谁产生。

统一字段：

- `device_id`：设备唯一标识，来自 `OPEN_DRONE_ID_BASIC_ID.uas_id`；
- `device_type`：`cns_box` 表示主控箱，`flight_controller` 表示 PX4；
- `school_name`、`dcdw_label`：归属信息，PX4 可以为 `null`；
- `capabilities`、`product`、`version`：设备能力、产品和版本元数据，可以为 `null`。

接口不提供 `vendor_id`、PX4 硬件 UID、树莓派编号或网关编号。不要按 `device_id` 前缀推断
设备类型，需要区分展示类型时使用 retained 状态中的 `device_type`。

## 2. 公网连接参数

| 参数 | 当前值 |
|---|---|
| Broker | `112.124.52.232` |
| TCP 端口 | `1883` |
| MQTT 版本 | MQTT 3.1.1 |
| 目录和状态 QoS | `1` |
| 实时遥测 QoS | `0` |

当前 Broker 为匿名明文服务，暂未通过 ACL 强制只读。软件部客户端只能订阅本文列出的 Topic，
不得向 CNS Topic 发布消息。

## 3. 全量设备目录

订阅：

```text
cns_rpi/events/devices/directory
```

该 Topic 为 QoS 1、retained 的完整快照。客户端每次收到后应整体替换本地设备目录，不要按
增量合并。

```json
{
  "schema_version": 1,
  "event_type": "device_directory_snapshot",
  "generated_at": "2026-08-05T10:00:00.000Z",
  "revision": 6,
  "devices": [
    {
      "device_id": "DCDWCNS1S2MEAG1VTA0C",
      "device_type": "cns_box",
      "school_name": "SEU",
      "dcdw_label": "DCDW-001",
      "model_version": "CNS v1.0",
      "capabilities": ["telemetry", "remote_id", "runtime_config"],
      "product": { "manufacturer_code": "DCDW", "model_code": "CNS1" },
      "version": null,
      "status": "online"
    },
    {
      "device_id": "PX4RID123456789ABCDE",
      "device_type": "flight_controller",
      "school_name": null,
      "dcdw_label": null,
      "model_version": "PX4",
      "capabilities": ["telemetry", "remote_id", "px4_official_control"],
      "product": { "manufacturer_code": "26", "model_code": "7" },
      "version": { "hardware": "42", "firmware": "1.17.3" },
      "status": "online"
    }
  ]
}
```

没有设备时 `devices` 为空数组。目录按 `device_id` 排序，会在服务启动、MQTT 重连、新设备
入库、设备上下线或目录元数据变化时重新发布。

## 4. 单设备当前状态与完整快照

订阅全部设备：

```text
cns_rpi/events/devices/+/state
```

`+` 代表一个 `device_id`。该 Topic 为 QoS 1、retained 的单设备完整当前快照；重连后可立即
恢复每台设备的最近状态。

```json
{
  "schema_version": 1,
  "event_type": "device_state",
  "event_at": "2026-08-05T10:00:01.125Z",
  "revision": 590,
  "device_id": "PX4RID123456789ABCDE",
  "device_type": "flight_controller",
  "school_name": null,
  "dcdw_label": null,
  "model_version": "PX4",
  "capabilities": ["telemetry", "remote_id", "px4_official_control"],
  "product": { "manufacturer_code": "26", "model_code": "7" },
  "version": { "hardware": "42", "firmware": "1.17.3" },
  "status": "online",
  "last_seen_at": "2026-08-05T10:00:01.120Z",
  "telemetry_received_at": "2026-08-05T10:00:01.120Z",
  "latest_telemetry": {
    "schema_version": 3,
    "device_id": "PX4RID123456789ABCDE",
    "device_type": "flight_controller",
    "sent_at": "2026-08-05T10:00:01.000Z",
    "telemetry": {
      "heartbeat": { "system_status": 4 }
    }
  },
  "change_reason": "telemetry",
  "degraded": false
}
```

说明：

- 外层状态事件 `schema_version` 为 `1`；
- `latest_telemetry` 是 RPi 上报的完整快照，内部 `schema_version` 固定为 `3`；
- 快照默认约 1 Hz，具体字段随设备能力扩展，客户端必须允许未知字段；
- 离线状态仍保留最后一份遥测，只能视为离线前的最后值；
- `change_reason` 可能为 `registration_online`、`registration_offline`、`telemetry`、
  `activity_timeout`、`database_recovered` 或 `snapshot_replay`。

## 5. 通用实时遥测（可选）

需要更高刷新率时额外订阅：

```text
cns_rpi/+/telemetry/realtime/v1
```

| 属性 | 值 |
|---|---|
| QoS | `0` |
| Retain | `false` |
| Schema | `1` |
| 频率 | 默认约 10 Hz，最高 20 Hz |
| 入库 | 否 |

实时外壳固定为 `schema_version`、`device_id`、`sequence`、`sent_at` 和 `telemetry`。
Topic 中的设备 ID 与 payload 的 `device_id` 必须一致。`telemetry` 是开放 JSON 对象，可以
包含主控箱 `motor`、PX4 动态字段或两者，接入方应忽略不认识的字段。

### 5.1 主控箱实时帧示例

```json
{
  "schema_version": 1,
  "device_id": "DCDWCNS1S2MEAG1VTA0C",
  "sequence": 12345,
  "sent_at": "2026-08-05T10:00:01.125Z",
  "telemetry": {
    "motor": {
      "pwm_us": [1100, 1200, 1300, 1400]
    }
  }
}
```

`pwm_us` 按电机 1–4 顺序排列，单位为微秒。

## 6. 命令行验证

订阅目录和全部设备状态：

```bash
mosquitto_sub \
  -h 112.124.52.232 \
  -p 1883 \
  -V mqttv311 \
  -q 1 \
  -i "software-read-本机唯一标识" \
  -v \
  -t 'cns_rpi/events/devices/directory' \
  -t 'cns_rpi/events/devices/+/state'
```

可选查看任意设备的实时帧：

```bash
mosquitto_sub \
  -h 112.124.52.232 \
  -p 1883 \
  -V mqttv311 \
  -q 0 \
  -i "software-realtime-本机唯一标识" \
  -v \
  -t 'cns_rpi/+/telemetry/realtime/v1'
```

## 7. 当前边界

该接口不提供历史查询、遥测补发、命令下发、命令 ACK、告警处置、数据库访问或 Broker
只读 ACL 保证。客户端离线期间的实时帧不会补发，重连后 retained 消息只恢复最新状态。
